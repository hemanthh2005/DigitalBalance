# DEMO_GUIDE.md — DigitalBalance 5–10 Minute Viva & Demonstration Guide

**Project Title:** DigitalBalance: An AI-Based Social Media Addiction Monitoring and Intelligent Child Safety System  
**Target Audience:** Project Evaluators, Viva Examiners, BE Engineering Panel  

---

## Step-by-Step Viva Demonstration Walkthrough

### STEP 1: Launch Application & Dashboard Overview (1 Min)
1. Launch DigitalBalance on Android device/emulator.
2. Observe the **Home Dashboard**:
   - Today's Digital Wellbeing Score (e.g. `72 / 100`)
   - Risk Level Badge (`LOW / MODERATE / HIGH RISK`)
   - Total Screen Time (e.g. `3h 42m`)
   - Top Used Applications list.

### STEP 2: Grant Permissions & Track Usage (1 Min)
1. If **Usage Access Permission** banner appears, click "Grant Permission".
2. Open Android Settings and enable Usage Access for DigitalBalance.
3. Open a few apps on the device (e.g., YouTube, Chrome, Instagram).
4. Return to DigitalBalance and click **Refresh** icon to demonstrate real-time usage stats update.

### STEP 3: Behavioral Risk Insights & Explainable AI (2 Mins)
1. Tap **Insights** on bottom navigation.
2. Explain the **3 Transparent Rule-Based Indicators**:
   - **Indicator 1 (Total Screen Time):** Max 40 points penalty.
   - **Indicator 2 (High-Risk Category Share):** Max 30 points penalty (Social/Gaming/Video % share).
   - **Indicator 3 (Session Open Frequency):** Max 30 points penalty (App open count).
3. Highlight the **"Why this score was calculated"** explainability section for the viva panel.

### STEP 4: Child Safety Mode & Protected Apps (2 Mins)
1. Tap **Child Mode** on bottom navigation.
2. Toggle **Child Safety Mode** to ON.
3. Add a protected application package (e.g., `com.instagram.android` or `com.google.android.youtube`).
4. Set a custom **Guardian PIN** (Default demo PIN is `1234`).
5. Ensure **Accessibility Service** is enabled when prompted.

### STEP 5: Protected App Access & Restriction Overlay (2 Mins)
1. Open the protected application from the phone launcher.
2. Observe the **Restriction Overlay Activity** blocking unauthorized access.
3. Tap **"Adult Verification & Guardian PIN"**.

### STEP 6: Camera-Assisted Adult Verification & PIN Unlock (2 Mins)
1. Observe the front camera preview powered by **CameraX** and **Google ML Kit Face Detection**.
2. Point camera at face:
   - Notice live feedback: *"Adult presence verified! Proceed to Guardian authentication."*
3. Enter Guardian PIN `1234` and tap **Authorize**.
4. Access is granted temporarily for 15 minutes!

## Standard Viva Questions & Simple Technical Answers

1. **Q: Why is it called "AI-Based"? Is there a trained deep learning addiction classifier?**  
   *A:* No. To remain academically truthful, the system uses an engineered rule-based behavioral risk scoring mechanism combined with Google ML Kit computer vision face detection. It does not make clinical medical diagnoses.

2. **Q: Is the adult verification doing Facial Recognition or identity matching?**  
   *A:* No. It performs transient camera-assisted face presence detection to confirm a live adult is present. Zero facial templates, embeddings, or camera images are stored on device or cloud.

3. **Q: How does Session Reconstruction handle midnight boundaries (23:50 to 00:20)?**  
   *A:* The `SessionReconstructor` engine automatically splits sessions at 00:00:00 midnight so 10 mins are recorded on Day 1 and 20 mins on Day 2.

4. **Q: How is backend API access secured?**  
   *A:* The Node.js Express API verifies Firebase Auth ID tokens in the Authorization header (`Bearer <token>`). The backend derives user identity strictly from `req.user.uid` generated by Firebase Admin SDK.
